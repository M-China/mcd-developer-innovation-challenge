# 麦当劳 Wrapped（mcd-wrapped）🎉

一个基于**麦当劳 MCP** 的 Skill：一句话给用户生成一份 Spotify Wrapped 风格的**麦当劳年度消费报告**——总花费、客单价、0 元薅羊毛单、最常点商品、招牌组合、时段/门店/城市画像、年度「麦门人格」认证，外加基于真实优惠的个性化点单建议。

## ✨ 亮点（对应评分维度）

| 评分维度 | 本 skill 的设计 |
| --- | --- |
| 实用性 / 创新性 | 把冰冷的订单流水变成可分享的年度报告；「0 元单占比」「麦门人格认证」是纯增量洞察，订单列表里看不到 |
| Agent 协作水平 | 工作流六步固定（拉数→清洗→算指标→判人格→出报告→给建议）；人格判定表让输出确定可复现；建议环节可主动调用 `available-coupons` 把建议落到真实优惠 |
| 工作流完整度 | 覆盖空账号、接口报错、字段缺失、已取消订单等边界；模板行块化，数据多少都能出报告 |
| 可用性 / 可复现性 | 数据契约来自 `order-list` 实测（含 `realTotalAmount` 单位为元、套餐子项字段名为 `name` 等实测坑位）；指标口径有明确定义公式 |
| 创意表达 | Wrapped 式深色金红视觉、人格认证徽章、基于真实数据的「判词」文案 |

## 🍟 使用方式

安装 skill 后对 Agent 说：

- 「生成我的麦当劳年度报告」
- 「我今年在麦当劳花了多少钱？」
- 「给我整一个麦门 wrapped」

Agent 会自动调用 `order-list`，几十秒后给你一份可在浏览器直接打开的 HTML 报告（`demo/mcd-wrapped-<年份>.html`），方便截图分享。

另外支持**站外团购补录**：0 元核销单很可能是抖音/美团团购券（钱花在站外），Agent 会在报告前主动询问；你也可以随时直接补记——

- 「我在抖音买了个 25 块的双人套餐券，昨天用的，记一下」
- 「那单 0 元的其实是团购券，29.9 买的」
- 「那一单里堡是团购券 25.8，薯条是 App 内买的」——支持**单品级补录**：一单里部分商品用站外券（混合单）也能分开记账

记录存在本地 `<工作区>/mcd-wrapped-records.json`，报告会把"应用内消费 + 站外实付"合成真实总花费，并区分「团购核销单」「混合单」和真正的 0 元薅羊毛单。

## 🔧 安装（ZCode）

把整个 `mcd-wrapped/` 目录复制到技能发现目录之一即可：

- 项目级：`<项目>/.agents/skills/mcd-wrapped/`
- 用户级：`~/.agents/skills/mcd-wrapped/`

前置条件：已配置麦当劳 MCP（`https://mcp.mcd.cn` + 个人 Token），并已登录产生过订单。

## 🔒 隐私

- 报告只聚合统计指标，**不输出**订单号、手机号、地址。
- 数据仅来自用户本人账号的 `order-list` 返回，报告不外发，保存和分享均由用户自己完成。
